# App build

The Android app will be built here on the Adamsville Suite pipeline
(web app + Android shell; see the top-level README's architecture note).

First build order:

1. Bookshelf screen (Moon+-style cover shelf) with EPUB import + cover
   extraction.
2. Reading screen on epub.js with place-keeping.
3. Footnote pop-ups.
4. Dictionary doorway (native intent bridge).

No APK is committed to this repo — builds are delivered as files, the repo
holds source (same rule as the game repo).
